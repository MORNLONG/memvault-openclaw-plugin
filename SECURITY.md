# Security Policy

If you find a security issue in `@mornlong/openclaw-memvault`, do not open a
public issue first.

Report it privately to:

- GitHub Security Advisories for this repository, or
- the maintainer at `https://github.com/MORNLONG`

Please include:

- affected version
- impact summary
- reproduction steps
- suggested fix if available

We will validate the report, prepare a fix, and disclose it publicly after a
patched version is ready.
